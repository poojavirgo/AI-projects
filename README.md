# AI Projects

A collection of hands-on AI and Python projects focused on practical LLM application development.

The goal of this repository is to explore and build small projects around:

- Large Language Models
- Prompt engineering
- RAG
- Embeddings
- Vector databases
- AI agents
- LangChain
- LangGraph
- FastAPI
- Ollama and local LLMs
- OpenAI-compatible APIs
- MCP and agent integrations

## Projects

### 1. Website Summarizer

A Python application that takes a website URL, extracts readable content, and generates a concise summary using a local LLM.

**Tech Stack**
- Python
- Requests
- BeautifulSoup
- Ollama
- Llama 3.2
- OpenAI Python SDK
- uv

**Flow**

URL → Fetch HTML → Extract Text → Send to LLM → Generate Summary
